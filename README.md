# Red Willow RP — BCSO GitHub Pages V3

A static, responsive HTML/CSS/JavaScript command and SOP portal for Red Willow Role Play — Blaine County Sheriff's Office.

## Files
- `index.html` — site shell and entry point
- `styles.css` — full responsive design
- `app.js` — navigation, page content, search, and copy buttons
- `assets/bcso-patch.webp` — optimized BCSO patch
- `404.html` — custom error page
- `.nojekyll` — keeps GitHub Pages from processing the static site with Jekyll

## Before publishing
Replace all `DRAFT / VERIFY` content with your approved Red Willow BCSO SOPs, department structure, radio/10-codes, server penal code, command list, vehicle list, forms, and official links.

## GitHub Pages
1. Create a repository named `red-willow-bcso`.
2. Upload the contents of this package so `index.html` is at the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.
5. GitHub will provide the published URL.

## Custom domain later
Use **Settings → Pages → Custom domain** and then configure DNS with your domain provider. Do not add a custom `CNAME` until you know the domain you are using.
